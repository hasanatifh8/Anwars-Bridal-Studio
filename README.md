# Anwar's Bridal Studio

A unisex salon website built with Next.js — services & pricing, our team, gallery, blog and appointment booking.

## Getting Started

1. Install dependencies
```
npm i
```
2. Run the development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Build (static export)

```bash
npm run build
```

Output is written to the `out/` directory.
